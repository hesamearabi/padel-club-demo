# کیوسک کلاب — باشگاه تخصصی پدل قائم‌شهر

نمونه‌کار کاملاً تعاملی سامانه رزرو آنلاین زمین پدل، ساخته‌شده با HTML5 / CSS3 / JavaScript خالص — بدون هیچ فریم‌ورک و بدون مرحله Build.

## اجرا و انتشار

- اجرای محلی: همین پوشه را با هر سرور استاتیک باز کنید (مثلاً `python3 -m http.server`) یا فایل `index.html` را مستقیم باز کنید.
- انتشار: مخزن را روی GitHub Pages سرو کنید — همه مسیرها نسبی‌اند (`./style.css`، `./app.js`، `fonts/Vazirmatn-*.woff2`) و هیچ درخواست خارجی ارسال نمی‌شود.

## امکانات

- **کنسول رزرو سه‌مرحله‌ای:** انتخاب زمین (۳ زمین)، تقویم هفت‌روزه جلالی، سانس‌های ۹۰ دقیقه‌ای از ۰۹:۰۰ تا ۲۴:۰۰ با فیلتر بازه زمانی.
- **جستجوی شناور به سبک علی‌بابا** روی هدر آبی معماری زمین — فیلتر واقعی ماتریس سانس‌ها.
- **تخفیف صبح:** ۲۰٪ برای سانس‌های ۰۹:۰۰ تا ۱۵:۰۰.
- **سبد چندسانسه (تا ۳ سانس)** با نوار پرداخت چسبان، اجاره ست راکت و توپ و بلیت دیجیتال با کد QR (SVG).
- **پنل بازیکن:** رزروهای پیش‌رو، کنسلی رایگان تا ۶ ساعت قبل (سانس فوراً آزاد می‌شود)، تاریخچه، عضویت و علاقه‌مندی‌ها.
- **پنل مدیریت:** ۴ شاخص زنده، نمودار ستونی هفتگی SVG، جدول رزروها با جستجو و فیلتر، ثبت رزرو حضوری/تلفنی، مسدودسازی سانس، تنظیم قیمت زمین‌ها و درصد تخفیف، صندوق پیام‌ها.
- **وبلاگ آموزشی** در نمای مجزا با فیلتر دسته‌بندی و مطلب‌خوان.
- **احراز هویت دو نقشی** (بازیکن / مدیر) با ورود سریع نمایشی.
- **بازنشانی داده‌های دمو:** بازگرداندن همه داده‌ها به حالت اولیه.

## ذخیره‌سازی

همه داده‌ها (رزروها، قیمت زمین‌ها، مسدودسازی سانس‌ها، علاقه‌مندی‌ها، پلن‌های عضویت، پیام‌های تماس و نشست ورود) در `LocalStorage` کلید `kioskClub.v3` نگه‌داری می‌شود.

## پالت و هویت بصری

آبی سلطنتی FIP (`#0F3D91`, `#1D4ED8`)، سفید خط زمین (`#FFFFFF`, `#F4F7FB`)، سبز لیمویی توپ پدل (`#65A30D`, `#84CC16`) و مرکبی عمیق (`#0F172A`, `#475569`). قلم وزیرمتن، خودمیزبان در پوشه `fonts/`.
